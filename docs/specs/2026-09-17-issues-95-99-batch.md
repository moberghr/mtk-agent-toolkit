## Findings

1. **#99 — `resolve-tech-stack.sh` map glob pathname-expands against the cwd.**
   `set -- $line` (line 161) is an unquoted expansion; from a repo root that has
   `backend/`, `backend/** dotnet` becomes `backend/Shop.Api backend/Shop.Api.Tests … dotnet`.
   Behavioral. Files: `scripts/resolve-tech-stack.sh`, `tests/hooks/test-resolve-tech-stack.sh`
   (fixture gets real entries under the mapped folder plus a `**` case).
2. **#97 — `smoke-boot` documented as an `evidence_channel` but rejected.**
   `.claude/schemas/handoff.schema.json` enum and `scripts/validate-handoff.sh`
   `VALID_CHANNELS` have 8 values; the taxonomy in `spec-sidecar-manifest.md` and
   `verification-before-completion` has 9. Behavioral (validator). Files: the schema,
   the validator, `tests/fixtures/handoff-evidence-channels.json`.
3. **#95 / #96 / #98 — Windows-native python3 writes CRLF to text-mode stdout; bash
   captures keep the `\r`.** One root cause, three symptoms: `setup-refresh-plan.sh`
   `--json` crash + miscounted summary, `workflow-artifact.sh` zero-arg `seal` "target
   not found", `manifest-preflight.sh` MP001 on every `modify`. Fix at the source: a
   one-line `sys.stdout.reconfigure(newline="\n")` prelude in every python heredoc /
   `-c` whose stdout bash parses (scripts/ + hooks/). The `seal` derivation also drops
   its unquoted `set -- $derived` (same class as #99). Behavioral. New regression test
   `tests/hooks/test-python-crlf-stdout.sh` runs the three reported scripts under a
   python3 shim that emulates Windows text-mode stdout.
4. **Comment on #95 correcting the root cause** (CR comes from python stdout, not a
   CRLF working tree; the proposed `add_row` strip treats one symptom).

# v7.8.0 plan — ai-ready borrows

Spec: `docs/specs/2026-05-19-v7.8.0-ai-ready-borrows.md`

## Batch 1 — PR review mining

**Goal:** A `gh`-backed script that mines repeated reviewer-feedback phrases from the last N merged PRs and outputs `[MINED:feedback]` candidates.

**Files:**
- NEW `scripts/pr-review-mine.sh` — bash + `gh` + `jq`. Args: `--prs N` (default 10), `--json`. Reads PR review comments, normalizes (lowercase, strip mentions/quotes/code-fences), n-gram clusters into 3–6-word phrases, filters via denylist. Output format: phrase | occurrence count | PR refs.
- NEW `.claude/references/pr-mining-patterns.md` — denylist (LGTM, ship it, thanks, nit, …), canonical mining heuristics, and the `[MINED:feedback]` output schema.
- NEW `.claude/skills/pr-review-mining/SKILL.md` — workflow skill (Overview / When To Use / Workflow / Verification) that wraps the script and explains how to evaluate output.
- NEW `tests/pressure-tests/pr-review-mining.md` — adversarial scenarios (single-occurrence false positives, sycophant comments, code-fence noise, auto-promotion attempt).

**Checkpoint:** `bash scripts/pr-review-mine.sh --prs 3 --json | jq .` returns valid JSON in this repo, even if no patterns match (empty array, not error).

## Batch 2 — 12-asset scorecard

**Goal:** A deterministic scorecard against the 12 named assets in the spec.

**Files:**
- NEW `scripts/repo-health-score.sh` — bash, no external deps beyond `jq`. Implements each asset check, emits markdown by default and JSON with `--json`. Medal logic from spec U6.
- NEW `.claude/references/repo-health-assets.md` — canonical 12-asset list with each pass/partial/fail rubric, denominator rules (n/a exclusions), and medal thresholds.

**Checkpoint:** `bash scripts/repo-health-score.sh` against claude-helpers itself emits a coherent markdown report with ≥6 🟩 and a 🥇 or 🏆 medal.

## Batch 3 — Monorepo ripple detection

**Goal:** When the repo is a monorepo, list downstream packages affected by a given changed file.

**Files:**
- NEW `scripts/monorepo-ripple.sh` — bash. Args: file paths. Detects monorepo type (pnpm-workspace.yaml / npm `"workspaces"` / Maven `<modules>` / dotnet `*.sln` / Python `pyproject.toml` with `libs/`). Resolves which package owns each input file; greps cross-package imports to compute reverse-dep set. Output lines: `RIPPLE <pkg>: affects <downstream-pkg>`.
- MODIFIED `.claude/skills/spec-drift-detection/SKILL.md` — add a "Ripple check" subsection that calls the script on the change manifest when monorepo detected.
- MODIFIED `.claude/skills/pre-commit-review/SKILL.md` — call the script on staged files; warning-level finding when ripples are non-empty.

**Checkpoint:** Running on a non-monorepo (claude-helpers root) produces no output and exits 0.

# Tech Stack: Python

## When To Use

## Build & Test Commands

No compile step: type checking and tests are the verification gates.

- **Type check (compile-equivalent):** `mypy .` or `pyright` (whichever the project uses)
- **Test (batch):** `pytest -q --tb=short <path/to/module>` or `pytest -q --tb=short -k <pattern>`
- **Test (full):** `pytest -q --tb=short`
- **Bounded output is the default.** Batch checkpoints run these through `bash scripts/mtk-verify-run.sh --label <batch-id>-<step> -- <cmd>` — the wrapper's bounded tail is the evidence, the log path is the receipt.
- **Format:** see `## Format Command`.
- **Lint:** `ruff check <path>` (or `flake8` / `pylint` per project)

Prefer project targets when present: `tox`, `poetry run pytest`, `make test`, `just test`.


## ORM & Data Layer Guidance

- **SQLite in-memory does not validate Postgres behavior** (JSONB, arrays, `ILIKE`, full-text search, advisory locks). Use `testcontainers-python` or a real test database when database semantics matter; for Django, `pytest-django` against Postgres.
- A sync DB driver (or `requests`) inside an `async def` endpoint blocks the event loop. Use a sync endpoint over a sync driver; do not fake `async`.
- Review Alembic autogenerated migrations before applying: it guesses, and reads a rename as drop + add.
- Writes run inside an explicit transaction (`with session.begin():`, `transaction.atomic()`), one commit per request or handler; audited writes follow `domain-finance.md`.

## Framework Patterns

Match the project's existing FastAPI, Django or Flask conventions. Two boundaries reviewers check: request and response shapes are validated models (Pydantic, DRF serializers, Django forms), never raw `dict` / `request.POST` in business logic; and side effects (email, queue, external calls) are explicit in the service layer, not buried in a model or serializer.

## Test Level Guidance

Endpoints, persistence, auth and serialization get integration tests (`TestClient`, Django `Client` / DRF `APIClient`); pure logic gets unit tests with `parametrize`. Frameworks, fixtures, mocking and the test database: `.claude/references/python/testing-supplement.md`.

### hooks (do NOT add)

`format-on-edit.sh` is wired by the plugin's own `hooks/hooks.json`. Bootstrap never copies an MTK hook into the target's `settings.json`; `setup-bootstrap` Settings Merge says why. Formatting runs at Stop, not PostToolUse, which matters most here: `ruff check --fix` rewrites imports and bindings, so a mid-turn run would change what a file means between the read and the next edit.

## Format Command

```bash
ruff format <file> && ruff check --fix <file>   # or black <file>
```

At flush the hook picks `ruff` → `black` based on what's installed, once per edited file (deduped, with files deleted during the turn dropped). Failures log to stderr but never block the edit.

## Scan Recipes

Used by `setup-audit` when auditing a Python repository.

### Dependency Registry Verification

Before planning the install of any PyPI package not already in `requirements.txt` / `pyproject.toml`, verify it exists and is the real one (criterion 0 of `.claude/references/dependency-intake-checklist.md`). Not found, or a typosquat-like name, is an immediate block; an unverified AI-recommended package is tagged `[ASSUMED]` with a `checkpoint:human-verify` step before any install.

```bash
pip index versions <pkg>
```

### Project Structure
```bash
find . -maxdepth 2 \( -name "pyproject.toml" -o -name "setup.py" -o -name "setup.cfg" -o -name "requirements*.txt" -o -name "Pipfile" -o -name "poetry.lock" \) 2>/dev/null
cat .python-version 2>/dev/null; grep -E "python_requires|python =" pyproject.toml setup.py setup.cfg 2>/dev/null | head -5
find . -maxdepth 3 -name "__init__.py" -not -path "*/.venv/*" -not -path "*/venv/*" -not -path "*/site-packages/*" | head -20
```

### Patterns In Use
```bash
grep -rlE "from (fastapi|django|flask)|import (fastapi|flask)" --include="*.py" | head -10
grep -rlE "from sqlalchemy|sqlalchemy\.orm|models\.Model" --include="*.py" | head -10
grep -rlE "from pydantic|BaseModel|marshmallow" --include="*.py" | head -10
grep -rl "async def" --include="*.py" | head -10
find . \( -name "mypy.ini" -o -name "pyrightconfig.json" \) 2>/dev/null; grep -E "mypy|pyright" pyproject.toml setup.cfg 2>/dev/null | head -5
```

### Data Layer
```bash
grep -rlE "DeclarativeBase|declarative_base|Mapped\[|session\.(execute|query)" --include="*.py" | head -5

grep -rnE "lazy=|create_engine|sessionmaker|SessionLocal" --include="*.py" | head -5
```
